Hackintosh Intel 网卡与蓝牙驱动配置记录

一言加载中...

person TonyChenn calendar_today 发布于 2023-08-05 edit_calendar 更新于 2026-08-20

适用范围

本文是基于 Intel AX210 与 macOS Monterey（12.x）的历史配置记录。不同 macOS 版本、OpenCore 版本、无线芯片和 BIOS 设置会改变可用驱动；开始前应先查看 OpenIntelWireless 兼容表，并备份可启动的 EFI。

选择 Wi-Fi 驱动

  • AirportItlwm.kext：与系统 Wi-Fi 菜单集成，但必须下载与 macOS 大版本匹配的构建。
  • itlwm.kext：通常需要配合 HeliPort 管理连接，适用范围和功能与 AirportItlwm 不完全相同。

两者不要同时加载。更新驱动前应确认当前系统版本，清理旧 kext 后再在 OpenCore 配置中保持条目与实际文件一致。

配置蓝牙驱动

蓝牙组件同样需要匹配 macOS 和驱动发行版本。本文使用过下列项目，加载顺序和是否需要其中某个组件应以对应发行说明为准：

  1. BlueToolFixup.kext
  2. IntelBTPatcher.kext
  3. IntelBluetoothFirmware.kext

验证与回退

  • 重启后确认 Wi-Fi、蓝牙开关、休眠唤醒和设备重连是否正常。
  • 若升级后无法进入系统，应从备份 EFI 启动并回退最近新增的 kext，不要在无法验证时同时升级 OpenCore、macOS 和所有驱动。
  • Hackintosh 不具备官方硬件支持，系统更新前应先确认驱动项目的兼容说明。
