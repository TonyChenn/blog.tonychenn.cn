本文只记录 C# 2.0 与 3.0 的早期语言特性，内容没有覆盖 C# 4.0 及之后的版本。因此保留为历史学习笔记，不作为完整版本总览参与搜索收录。

C# 2.0

  1. 新增功能泛型。
  2. 新增可空类型。
  3. 新增迭代器。
  4. 新增分部类
  5. 新增匿名方法。
  6. getter/setter 单独设置访问权限。

C# 3.0

  1. 自动实现的属性。
  2. 匿名类型。
  3. 隐式类型var
  4. 拓展方法
  5. 新增分部方法
  6. 查询表达式
