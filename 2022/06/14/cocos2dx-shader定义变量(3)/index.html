把 Lua 中的颜色传给片元着色器，使同一张图片渲染为不同颜色。

实现目标

传递颜色变量到 Shader，使图片渲染出不同的颜色：

如何定义变量与赋值

在 Shader 中使用 uniform 声明变量，再通过 GLProgramState 的 setUniformXXX(name, value) 接口赋值。

Cocos2d-x 3.17.2 常用接口

GLSL 类型 C++ 接口 用途
int、bool setUniformInt 布尔值通常以 0 或 1 传入
float setUniformFloat 单个浮点值
float[] setUniformFloatv 浮点数组，需要数量参数
vec2 / vec3 / vec4 setUniformVec2 / setUniformVec3 / setUniformVec4 单个向量
vec2[] / vec3[] / vec4[] setUniformVec2v / setUniformVec3v / setUniformVec4v 向量数组，需要数量参数
mat4 setUniformMat4 4×4 矩阵
sampler2D setUniformTexture 绑定纹理，不用于传布尔值

这张表对应 Cocos2d-x 3.17.2 的 GLProgramState C++ 接口。不同 Lua 绑定版本未必暴露所有数组重载，使用前需要在当前引擎绑定中确认。

状态共享注意事项

getOrCreateWithGLProgram 会复用与 GLProgram 对应的状态。多个节点共用该状态时，后设置的 uniform 可能影响其他节点。需要每个节点保持独立参数时，应创建或克隆独立的 GLProgramState。
